# Purpose

This document defines the wireframes required for the House of Lady Amour website.

Wireframes will establish page structure, content hierarchy, navigation, calls to action, and responsive behavior before visual design and development begin.

The goal is to resolve layout decisions before writing production code.

---

# Wireframe Principles

Every wireframe should:

1. Begin with the user’s primary goal.
2. Present the most important content first.
3. Use clear navigation.
4. Include visible calls to action.
5. Avoid overcrowding.
6. Support mobile, tablet, and desktop layouts.
7. Identify required images and written content.
8. Include accessibility considerations.
9. Show how users move to the next relevant page.
10. Support the House of Lady Amour room-based experience.

# Wireframe Review Questions

Before approving each wireframe, ask:

1. What is the visitor trying to accomplish?
2. Is the primary action obvious?
3. Is the most important information shown first?
4. Does the layout support mobile users?
5. Is the page overcrowded?
6. Can a visitor reach related content naturally?
7. Are images and written assets identified?
8. Are accessibility needs considered?
9. Does the page feel like part of the House of Lady Amour?
10. Can the layout be built with reusable components?
