# Purpose

This document tracks the written content, images, videos, product information, and brand assets required to design and develop the House of Lady Amour website.

The website should not move into full development until the highest-priority assets have been identified, prepared, and organized.

# 15. Minimum Assets Required Before Coding

The following assets should be prepared or clearly defined before full development begins:

1. Approved logo and favicon.
2. Final brand colors and typography.
3. Homepage headline and introduction.
4. Homepage hero image or video.
5. Final About page biography.
6. High-resolution Ameliah’s Story cover.
7. Book synopsis and Amazon link.
8. Initial recipe list.
9. At least six finished recipe images.
10. At least six featured YouTube videos.
11. At least four Shopify products or approved product mockups.
12. Product names, descriptions, prices, and images.
13. Website navigation structure.
14. Legal-policy plan.
15. Domain and hosting decision.
