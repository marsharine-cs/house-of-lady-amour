# Purpose

This document defines the primary user archetypes for the House of Lady Amour platform. These personas represent the motivations, goals, behaviors, and needs of the people who will interact with the website.

Understanding these users guides decisions related to navigation, accessibility, content strategy, e-commerce, and user experience.

---

# Persona 1 — The Emerging Professional

## Age

24–35

## Description

A young, college-educated adult entering the workforce and navigating new environments, relationships, faith, family, and career choices. She enjoys meaningful fiction that encourages hope, resilience, and personal growth.

## Goals

- Discover contemporary romance novels
- Read inspiring stories
- Learn about the author
- Participate in book discussions
- Purchase current and future books

## Frustrations

- Stories without emotional depth
- Poorly organized book websites
- Difficulty finding book order or purchasing information

## Website Needs

- Beautiful book pages
- Reading order
- Reviews
- Author insights
- Book discussion announcements
- Easy purchasing

---

# Persona 2 — The Home Cook

## Age

35–65

## Description

Someone who enjoys preparing meals for family and friends while learning traditional recipes, baking, and wood-fire cooking techniques.

## Goals

- Discover recipes
- Learn traditional cooking methods
- Watch cooking videos
- Purchase cookbooks

## Frustrations

- Poor recipe organization
- Missing ingredient lists
- Low-quality food photography

## Website Needs

- Recipe categories
- Printable recipes
- Beautiful photography
- Embedded YouTube videos
- Cookbook previews

---

# Persona 3 — The Inspired Lifestyle Shopper

## Age

25–60

## Description

A shopper looking for thoughtful gifts and beautiful everyday products that reflect creativity, faith, hospitality, and simple living.

## Goals

- Discover journals
- Shop home goods
- Purchase gifts
- Explore seasonal collections

## Frustrations

- Confusing navigation
- Poor product photography
- Difficult checkout

## Website Needs

- Elegant product pages
- Lifestyle photography
- Secure checkout
- Product recommendations

---

# Persona 4 — The Content Explorer

## Age

18–70

## Description

A visitor who first discovers Lady Amour through YouTube or social media and wants to explore recipes, books, travel, countryside living, and future content.

## Goals

- Watch videos
- Explore recipes
- Learn about the brand
- Subscribe to updates

## Frustrations

- Broken links
- Slow websites
- Difficult mobile navigation

## Website Needs

- Embedded playlists
- Video categories
- Related recipes
- Newsletter signup
- Mobile-friendly experience

---

# Persona 5 — The Technical Recruiter

## Description

A recruiter, engineering manager, or technical interviewer evaluating this GitHub repository as evidence of software engineering ability.

## Goals

- Assess planning ability
- Review architecture
- Evaluate documentation
- Examine code quality
- Understand technical decisions

## Frustrations

- Missing documentation
- Disorganized repositories
- No deployment
- No testing
- Lack of project structure

## Repository Needs

- Professional README
- Clear documentation
- Software architecture
- Responsive design
- Accessibility
- Testing strategy
- Meaningful commit history
- Production deployment
- Clean project organization
