# Purpose

This document defines how the House of Lady Amour project will be managed throughout its lifecycle.

Rather than treating development as a collection of unrelated coding tasks, this project follows an organized workflow inspired by modern Agile software development practices.

The objective is to maintain a transparent, well-documented, and scalable development process while demonstrating professional engineering practices.

---

# Project Management Methodology

The project follows an iterative Agile-inspired approach.

Development is organized into small, manageable pieces of work that can be completed, reviewed, tested, and improved over time.

---

# Pull Requests

Every significant feature should include:

- Summary
- Screenshots when applicable
- Linked GitHub Issue
- Testing notes
- Accessibility checklist

---

# Definition of Done

A feature is considered complete when:

- Requirements are satisfied.
- Code is reviewed.
- Accessibility has been verified.
- Responsive layouts work.
- Tests pass.
- Documentation is updated.
- Feature is deployed successfully.

---

# Success Philosophy

Every task completed should improve at least one of the following:

- User experience
- Accessibility
- Performance
- Maintainability
- Brand consistency
- Developer experience
