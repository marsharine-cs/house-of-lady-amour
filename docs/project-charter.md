# Project Charter

## Project Name

House of Lady Amour

## Project Owner

Marsharine A. Simpson

## Project Type

Lifestyle, publishing, media, recipe, and e-commerce web platform.

## Project Purpose

The House of Lady Amour will serve as the central digital home for the Lady Amour brand. It will connect books, recipes, videos, Shopify products, creative projects, and faith-centered lifestyle content through an immersive, room-based website experience.

The project will also serve as a professional software-development portfolio project demonstrating planning, user-experience design, responsive web development, accessibility, e-commerce integration, testing, documentation, and deployment.

## Problem Statement

Lady Amour currently has books, YouTube content, recipes, future merchandise, and several planned product categories, but these experiences are not yet connected through one organized digital platform.

Visitors need a clear and welcoming place where they can discover the brand, browse content, purchase products, watch videos, read recipes, and learn about upcoming releases.

## Project Vision

To create an elegant and welcoming digital estate where every section of the Lady Amour brand feels like entering a different room within one beautiful home.

## Primary Objectives

1. Create a professional and responsive Lady Amour website.
2. Integrate Shopify products and secure purchasing options.
3. Showcase books, recipes, videos, journals, and future products.
4. Organize the brand through the rooms of the House of Lady Amour.
5. Build an accessible and mobile-friendly user experience.
6. Improve brand recognition and search-engine visibility.
7. Create a documented software project suitable for a professional GitHub portfolio.
8. Establish a scalable foundation for future products and content.

## Primary Audience

- Romance readers
- Cookbook and recipe enthusiasts
- Lady Amour Vlogs viewers
- Faith-centered lifestyle audiences
- Jamaican food and rural-living enthusiasts
- Online shoppers
- Potential business partners
- Recruiters and hiring managers reviewing the technical project

## Initial Scope

The first release will include:

- A responsive homepage
- Brand introduction
- Author biography
- Book pages
- Recipe and cookbook previews
- YouTube video integration
- Shopify product integration
- Email subscription option
- Contact form
- Mobile, tablet, and desktop layouts
- Search-engine optimization foundations
- Accessibility foundations
- Testing and deployment documentation

## Out of Scope for the First Release

The following may be added in later phases:

- Custom payment processing
- Native mobile application
- User accounts
- Customer discussion forums
- Subscription memberships
- Product manufacturing systems
- Advanced recommendation engines
- Multilingual support
- Custom inventory-management software

## Project Constraints

- The website will be developed incrementally.
- Product images and written content must be prepared before development.
- Shopify will handle product checkout and payment security.
- The project must remain manageable for one primary developer.
- The design must support future brand growth without requiring a complete rebuild.

## Assumptions

- A Shopify store will be available for product management.
- High-quality brand and product images will be created.
- YouTube videos will remain hosted on YouTube.
- The website will use a modern hosting platform.
- The GitHub repository will remain publicly viewable as a portfolio project.

## Success Criteria

The project will be considered successful when:

1. Visitors can clearly understand the Lady Amour brand.
2. The website works well on mobile, tablet, and desktop devices.
3. Visitors can discover books, recipes, videos, and products easily.
4. Shopify products can be viewed and purchased securely.
5. The website meets defined accessibility and performance goals.
6. The project includes clear technical documentation and testing.
7. A working production version is publicly deployed.
8. The GitHub repository presents the project professionally to recruiters.
